# Token Town · 河谷小镇

把 AI coding token 变成建设资金，在一片 3D 河谷里经营自己的小镇。每次玩 5–10 分钟，规划街道和社区，看村民种麦、磨面、烤面包，让小镇随着昼夜和四季慢慢生长。

**同步 token → 获得金币 → 建设与布置 → 改善居民服务 → 完成委托 → 解锁土地、建筑和装饰。**

## 本地运行

需要 Node.js 22+。

```bash
npm install
npm run dev
```

打开 [河谷小镇](http://127.0.0.1:4173)。真实模式通过本地服务读取 Claude Code / Codex 使用记录；没有历史记录也可以接通起步街道、游玩免费规划关，或选择演示城镇。

[演示城镇](http://127.0.0.1:4173/?demo=1) 提供四个虚构项目。首次同步得到 400 金币，之后每次模拟使用增加 80 金币。演示和真实进度分别保存。

## 开始建设

1. 同步使用记录，兑换建设金币。
2. 打开建设目录，选择建筑或直接拖出目录。预览模型跟随指针，Q / E 调整朝向，点击或松开拖动放下。
3. 给建筑门口接上道路，连通镇公所。选中建筑可以查看入口、服务范围、容量和缺少服务的原因。
4. 改善住宅的食物、绿地和休闲需求，完成委托，逐步开放新土地和建筑。
5. 尝试六张免费规划关：用固定建筑和道路额度挑战更好的布局，解锁装饰蓝图与配色。

起步套件包含镇公所、四栋住宅、面包店和公园。建筑立即落成，购买的实例永久保留；铺路、搬迁、旋转、收纳和重新摆放都免费。

## 居民服务怎么算

委托进度统计**获得服务的住宅数量**，同一栋住宅的同一项需求只计一次。增加商店或公园后，需要让更多住宅真正获得服务，进度才会提高。

- **连路：**住宅和服务设施的入口必须通过道路接到镇公所；旋转建筑也会改变入口。
- **食物：**面包店最多服务 6 栋住宅，入口之间的最短道路距离不超过 8 格；集市最多服务 12 栋，距离不超过 12 格。
- **休闲：**咖啡馆最多服务 4 栋住宅，最短道路距离不超过 10 格。
- **绿地：**公园须连路，住宅和公园占地最近边缘的曼哈顿距离不超过 3 格即可覆盖。

商店优先分配给道路距离较近的住宅；距离相同时按稳定建筑编号分配。果蔬铺、花艺店和书屋有各自的容量与距离，可在建筑详情查看。多个设施覆盖同一住宅不会叠加进度，纯装饰也不会提供居民服务。

## 农事、昼夜与四季

在建设目录的「农事」中购买河岸麦田（6 金币）和风车磨坊（32 金币），将它们与住宅、面包店一起接到镇公所道路网络。最多三位村民参与生产：

**播种 → 生长 → 收割 → 运麦 → 磨面 → 送粉 → 烘焙。**

每批 2 小麦加工成 2 面粉，再烤成 4 面包。村民沿道路运输，作物、货物和磨坊叶片会随生产变化；农事面板显示库存以及断路、缺设施、缺居民或缺原料的原因。农事库存独立于住宅服务计算，面包不兑换金币。

六分钟过一天，每三天换一季。夏天麦子长得更快，冬天更慢；村民晚上开门回家睡觉，清晨出门继续工作。夜间和道路中断会暂停生产，恢复后续做。时间和农事进度自动保存，离开游戏不计算离线产出。

四季分别播放轻音乐，切换季节和循环播放时平滑淡入淡出。音乐在首次操作后开始播放，设置中可单独开关和调整音量，也可以固定时段或季节。

## 操作

| 操作 | 控制方式 |
|---|---|
| 放置建筑 | 选择或拖出目录，预览跟随指针，点击 / 拖放落地 |
| 旋转待放建筑 | Q / E；R 也可旋转 |
| 取消放置 | Esc / 右键 |
| 平移镜头 | WASD；浏览时按下拖动，摆放时中键拖动 |
| 连续旋转镜头 | 浏览时按住 Q / E 或镜头旋转按钮，松开停止 |
| 触控板调整视角 | 两指上下滑改变俯仰，左右滑旋转 |
| 触控板缩放 / 平移 | 捏合缩放；Shift + 两指滑动平移 |
| 鼠标缩放 | 设置切换为鼠标模式后，滚轮缩放 |
| 查看建筑 | 点击建筑，查看详情与服务覆盖 |

WASD 在摆放建筑时也可移动镜头，输入框中不会拦截文字输入。精确格子输入可作为辅助放置方式。设置提供精细 / 中等 / 轻量画质、总静音和减少动态效果。

## 金币、存档与隐私

每 10,000 新 token 兑换 1 金币，不足一枚的零头继续累计。首次同步可以兑换已有历史；之后按每个项目的兑换高水位计算增量，重复同步或历史减少后恢复都不会重复发币。工坊等级没有金币倍率。

六章基础委托分别提供 5 / 10 / 15 / 20 / 25 / 30 金币的补贴权益，只领取一次。累计实际补贴最多为累计 token 金币的 20%；额度不足的部分保留，后续同步再补发。没有维护费或离线惩罚。

本地服务仅监听 `127.0.0.1`，通过 `GET /api/usage` 提供聚合结果。只汇总项目名称、来源和 token 数量，不展示完整对话，不上传使用历史，也不根据提交、测试、PR 或工作质量发放奖励。

存档保存在当前浏览器的 `tokenTown.slot.live.v1` / `tokenTown.slot.demo.v1` 中。更换浏览器或本地地址前，可以在设置中导出备份；导入时需要使用对应的真实或演示模式。

## 开发与验证

```bash
npm run typecheck
npm test
npm run build
```

`npm run build` 生成 3D 资产、前端与本地服务；构建后用 `npm run start` 启动。开发时可在另一个终端运行 `npm run watch`，监听前端源码变化。

游戏规则独立于场景渲染。规则测试覆盖金币高水位、零头累计、补贴、道路与服务分配、建筑占地、库存、存档、章节和关卡解法；动画与交互测试覆盖村民交通、坐姿、昼夜出入、农事暂停恢复和镜头控制。浏览器验收应使用独立地址或测试存档，保留玩家进度。
