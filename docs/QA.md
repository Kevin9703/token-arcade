## 服务和生活表现检查

服务进度一轮使用现有演示城镇作只读观察：397 金币，第二章，五栋已摆住宅，其中四栋连路并获得食物、一栋满足绿地；第五栋入口断开时有明确解释。公园入口未连路不会显示有效绿色覆盖，范围反馈复用规则计算，工坊不计入住宅。

居民行走测试使用四种道路拓扑模拟十二分钟，并检查两轮睡眠 / 清晨出门；间距、转向和持续移动没有出现已复现的聚堆或抽搐。浏览器观察了开门回家、夜间刷新、清晨回到步行或座位。坐姿与旋转门轴另有几何测试。

主城曾在 574 × 853 CSS 视口、2×画布密度检查中文 HUD、设置和建筑详情，观察春夏秋冬与夜景。所有模型继续使用实际 GLB 或同源完整网格，资产检查未覆盖用户打开的 Blender 编辑。
