## 本地反馈

`docs/feedback.md` 是玩家持续补充的本地文件，已加入 Git 忽略规则，不随仓库发布。保留原文，完成并验证后勾选；只有设计或部分实现的事项必须明确标注。开发开始、完成一批工作和提交前都要查看。没有该文件的全新检出可按路线图继续，不要求创建虚构反馈。

废弃的策划、交接、发布说明和重复验收已删除；历史内容可从 Git 历史查阅。
