## 邻里订单与丰收小集会

完成时消费面包和原料库存，先校验再记账；蓝图分别是围裙架、野餐长桌、麦穗旗。解锁后正常购买，提供四款外观，重复完成只记录分享次数。没有自动铸币、抽奖、限时或签到要求。

镇公所前的聚会沿既有道路错峰到达，使用三个独立停留位置。工作优先，夜晚仍正常回家，不能让庆祝成为新的拥堵来源。

## 饭馆与种植养殖

饭馆用宽瓦顶、户外餐桌、厨房侧翼与烟囱区别于面包店和咖啡馆。土豆 / 胡萝卜可切换；牛棚产奶并加工奶酪，保留一份鲜奶作加工种子；猪圈采用寻松露，不引入屠宰。三款菜谱分别为土豆浓汤、田园奶酪拼盘、河谷炖鱼。

每批小麦磨成三份面粉，其中两份预留面包批次，剩余实际运到厨房。到达才收货，菜谱在开工时扣料，批次中切换排到下一轮。原料留在来源设施、运输货物或厨房库存，界面明确显示数量和缺口。

最多三名现有居民共享生产：麦田留一个工位，新链按完成批数轮换。配送中途不抢人；门口独立装载点、双侧避让与路面重入预留避免互相卡住。昼夜、断路、刷新和跨窗口存档均保留状态。

## 河边钓鱼小屋

仅允许河岸陆地、门朝陆地且码头朝河水；南北岸分别使用朝向 0 / 2。预览显示合法岸边，保存导入复用同样校验。原创建筑包含完整木屋、渔网、木桩和码头。村民走到独立钓位、抛竿、收鱼，再运到饭馆；夏天较快，没有随机损失。

2026-10-01 可观察性补充：生产沿用三人轮班与原库存规则；增加「看看码头」镜头入口，南北两岸均从水面侧露出钓位。状态显示实际工人的名字、前往 / 到岗动作；没有工人、夜间、断路或库存满时明确解释。优先解决钓位遮挡和状态误读，没有把观察镜头变成调度任务或新增产量。

同批修复：已满仓的钓鱼小屋在饭馆接通后，可以由实际到达的工人领取库存鱼并配送；不用再生产一批才能启动运输。夜间 / 断路保留货物，到达才入厨房，不重复创造鱼。厨房达到十二份时提示切换河谷炖鱼并准备土豆，沿用最多三名工人。

## 四季规划选择

## 2026-10-01：移动速度与河道决定

WASD 标准速度由缩放 1 时每秒 12 格提高至 24 格；起步缩放 1.7 时实际约每秒 14.1 格。设置提供舒缓 / 标准 / 快速，Shift 临时加倍；街道行走标准速度从 2.6 提高至 3.6 格 / 秒，遵循同一速度偏好和加速。斜向归一、缩放补偿、松键停止及输入框保护保留。速度偏好按真实 / 演示独立保存，旧存档补标准速度。

用户选择「算了先这样吧」：本轮保持可玩区域的直河、桥位和两岸布局，不重塑河道。自然 S 弯河道需要统一水域格子、桥位、钓鱼岸线、地形高度和两岸解锁规则；若以后重启，应先制作独立地图样板再讨论旧城迁移，避免仅弯曲水面而让通行与建设仍按直河计算。

## 下一阶段玩法方案（草案，尚未开发）

### 第一阶段：先让村民有可完成的故事

先选择三个现有居民，每人三段短心愿：第一段分享实际库存，第二段改善其住宅的服务或绿地，第三段布置一个可达的公共聚会地点。请求中的住宅和设施引用实际建筑实例；搬迁后继续按新布局计算，不能用建造数量替代服务结果，也不能虚构村民工作。

每段提供短对话和可追踪目标，完整故事解锁对应的门牌、庭院或纪念装饰蓝图。没有额外金币、签到、失败惩罚或离线倒计时；玩家暂停几天回来仍可继续。已完成心愿永久保存，领取、跨窗口和刷新不能重复消耗材料或重复解锁。三条故事都应提供不依赖额外 token 的起步段，后续需要建设时明确显示所缺设施。

### 第二阶段：四季改变小镇的活动

扩展已有秋日丰收会，加入春日花会、夏日河畔野餐、冬日灯市。每场活动只设两个准备目标：交付适季食物，以及安排接路、邻近绿地或服务的公共空间；不增加新的消费货币。活动分准备、布置、分享三个阶段，由玩家主动开始，季节结束保留准备进度，不强迫赶时间。

活动提供基础完成与更优布局两档成果，奖励季节装饰蓝图和配色。使用已有居民错峰到达及独立停留点，最多三名生产工人的规则保留；夜间按正常作息回家。已有三种订单继续可玩，节庆不会重复铸币。

### 第三阶段：让扩展土地有探索目标

先做三个可修复地标，分别组织河岸、林地和台地的游览路径。地标通过连路、实际原料运输及小型布局目标修复，完成后成为可观赏地点并解锁周边装饰；不额外提高 token 兑换倍率。遗址只在空闲扩展区域生成或由玩家选择放置，不覆盖既有建筑、道路和库存，不强制挪走老城。

开发前先验证三个地标的可达布局及材料来源；接入现有工人和配送，不增加独立后台模拟。先完成一个修复流程、游览行为与存档，再扩展其余两处。自然弯河属于以后可选的地图项目，不作为这些玩法的前置条件。

### 实现与验收顺序

先交付一名村民的完整三段心愿样板，检查是否比重复订单更有趣，再扩展三人；随后做一季活动样板，最后做一处地标。每个样板同时完成目标解释、场景反馈、存档迁移与材料事务验证。当前只完成方案整理，以上故事、节庆与修复均未进入游戏。
