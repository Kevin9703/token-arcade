# 河谷小镇 · 当前游戏规则

更新：2026-09-30。本文描述已实现的规则；尚未实现的订单、饭馆、养殖和钓鱼设计见 [开发路线图](ROADMAP.md)。

## 定位

5–10 分钟的本地城镇经营游戏。同步 AI token → 金币 → 买入并布置建筑 → 通过道路改善服务 → 完成委托 → 土地、建筑和装饰解锁。主屏始终是 3D 河谷小镇，现代 DOM 字体与安静 HUD。

起步固定套件：镇公所、四栋住宅、面包店、公园，没有额外赠送金币。建筑立刻落成，永久保留实例。道路、旋转、搬迁、收纳与再次摆放免费，无维护费、计时施工或离线惩罚。

入口取建筑朝向前方中间的格子。道路通过镇公所入口 BFS 求连通；服务沿连通道路最短路径传播。候选服务按距离、店铺稳定 ID、住宅稳定 ID 排序，容量用完后停止；同距结果不会随机变化。居民巡游和视觉动画不决定住宅服务或金币。视觉居民按实际位移迈步、摆臂，沿道路边界内缩形成的圆角闭环巡游，保持前后间距；固定车道不反复改向。夜晚逐户开门进入住宅睡觉，清晨预约路面空位再出来。纯装饰不会替代食物、休闲或绿地服务。

24×24 地图，河道在第 12–13 行（零基 11 / 12），不可建造；桥位横第 5、11、17、21 格。起步开放南岸前 18 列（198 格可建陆地，比原先多 50%）；河岸水面仍不可建设。完成第二章开放同岸东区；第三章开放石桥和对岸先遣区（西半岸第 4–11 行），使第四章跨河目标可解；第四章开放完整西侧对岸；第六章开放全图。

## 项目工坊

每个 AI 项目免费获得一栋 2×2 工坊，沿用 `src/domain/levels.ts` 的 50 级曲线。累计 token 和兑换高水位不会因扫描历史减少而下降。工坊可自由摆放或收纳，不增加金币倍率，不计作住宅，也不提供居民服务。

| 视觉阶段 | 等级 | 累计 token 范围 |
|---|---|---|
| 木屋 | 1–4 | 0–99,999 |
| 工坊 | 5–9 | 100,000–999,999 |
| 工作室 | 10–19 | 1,000,000–9,999,999 |
| 创作馆 | 20–34 | 10,000,000–49,999,999 |
| 河谷地标 | 35–50 | 50,000,000 及以上 |

等级之间采用固定锚点的几何插值；50 级门槛为 500,000,000 token。等级只影响视觉成长。

## 经济

每 10,000 新 token 铸 1 金币，零头累积。首次同步允许兑换历史；每个项目保存只增不减的兑换高水位，重复同步、历史删减 / 恢复都不会重领。没有项目等级倍率。

六章首次基础目标解锁经营补贴权益 5 / 10 / 15 / 20 / 25 / 30。已付累计补贴 ≤ floor(累计 token 金币 / 5)。未付款权益保留，下一次 token 同步结算。提高星级不再增加补贴。

## 六章与永久星级

基础目标全部满足后获得一星并开放下一章。两个额外目标各加一星，最高三颗；已记录星级永久保留，额外星级解锁对应建筑纪念配色。镇公所庭院原生 3D 纪念星同步展示成果。

| 章 | 基础目标 | 两个额外目标 |
|---|---|---|
| 1 在这里落脚 | 4 户连路且有食物 | 2 户绿地；道路 ≤16 |
| 2 绿荫街坊 | 6 户食物；4 户绿地 | 6 户绿地；道路 ≤24 |
| 3 热闹市集 | 8 户食物；6 户休闲 | 8 户休闲；6 户全部需求 |
| 4 河的另一边 | 桥连接，北岸 2 户食物，南岸 4 户食物 | 北岸 4 户食物；两岸各有全部需求住宅 |
| 5 紧凑而舒适 | 12 户全部需求；道路 ≤40 | 道路 ≤36；14 户全部需求 |
| 6 我们的河谷 | 16 户全部需求，两岸各至少 4 户，连路钟楼 | 20 户全部需求；道路 ≤64 |

第一章介绍连路和食物，第二章引入绿地，第三章引入休闲。需要查看入口和服务覆盖时，选择建筑即可显示；服务商店显示自身已服务住宅和仍缺服务住宅。

委托进度统计获得服务的**住宅**，同一需求每栋只计一次；重复覆盖不会叠加。目标卡提示住宅不足或缺少的服务。委托面板区分已摆住宅、连路住宅、食物和绿地满足数，支持逐栋查看缺少服务的具体原因并定位建筑。商店详情区分范围内住宅与实际分配的服务容量；公园显示三格范围及真正满足绿地的住宅，入口未连路时不会显示有效绿地覆盖。范围可视化和反馈使用与规则一致的入口、距离和服务分配结果，不改变存档或奖励。

## 控制与存档

玩家操作见 [README 操作表](../README.md#操作)。建设采用跟随指针的模型预览，目录可点击选择或拖出；校验通过后扣费，无效位置标红。坐标输入是可选辅助功能。

- 摆放时 Q / E 旋转建筑，R 为别名；右键 / Esc 取消。
- 浏览时按住 Q / E 或镜头按钮持续旋转，松开停止；WASD 随时平移镜头，输入框不拦截文字。
- 触控板上下滑改变俯仰，左右滑旋转，捏合缩放，Shift + 两指滑动平移；鼠标模式使用滚轮缩放。
- 镜头俯仰限制在 26°–72°，保持世界水平；手势、聚焦、俯瞰和缩放按时间平滑过渡，减少动态效果时即时响应。
- 回到小镇恢复 40° 俯仰；镜头变化时待放建筑重新投射到指针下方。

真实和演示存档独立，保存金币账本、项目高水位、建筑库存 / 布局、星级、配色、规划关、时钟、农事和设置。既有历史存档保留，不迁入新城镇。没有本地历史时不制造真实 token，明确提供演示入口。详细保存与跨窗口行为见 [架构](../ARCHITECTURE.md#存档与跨窗口保护)。

首版没有战斗、多人、随机抽取、室内装修或第二货币。

## 农事生产

河岸麦田（3×2，6 金币）与风车磨坊（3×3，32 金币）第一章即可购买。装饰小风车不参与生产。现有邻居负责播种 → 生长 → 收割 → 运麦 → 磨面 → 送粉 → 烘焙 → 回田，每批 2 小麦变 2 面粉，再变 4 面包。

- 麦田、磨坊、面包店及住宅入口必须接到镇公所；运输走道路最短路，不直线穿墙。
- 最多三位村民务农，任务等村民到达工作位置后推进。夏天生长较快、秋天较慢、冬天更慢，其余阶段不受季节增益影响。
- 断路、夜间、离开游戏或游玩规划关时暂停主城生产，恢复后续做，不重复发货或收获。
- 农事库存和每块田的批次、阶段单独保存，不兑换金币，不改变住宅服务或章节目标的计算。
- 农事面板和建筑详情解释断路、缺磨坊、缺面包店、缺居民；面包店详情区分缺面粉、面粉运输中、烘焙中和夜间休息。
- 道路修改保留居民实例、位置、坐姿、睡眠、累计步行和步态，只重新规划路线。

## 昼夜、四季与音乐

六分钟过一天，每三天换一季，从春季 09:00 开始。20:00 回家、06:00 出门：居民依次开门、进入住宅、在室内睡眠，清晨预约安全道路位置后出门。窗灯、日光和季节景观渐变，冬季有积雪与低密度飘雪。

设置支持固定时间 / 季节；时钟和偏好在真实 / 演示存档分别保存，隐藏或关闭页面时暂停，没有离线产出或惩罚。

四季音乐在首次操作后播放，跨季与循环边界用三秒交叉淡化。音乐有独立开关和音量，总静音与隐藏标签页会暂停音乐。音频本地提供；Kevin MacLeod 的曲目与 CC BY 4.0 署名见 [音乐授权](../public/assets/town/audio/CREDITS.md)。

## 规则与表现的边界

道路、需求、金币和解锁独立于渲染计算；农事阶段与库存有单独规则，村民到达情况用于推进工作。新增模型、粒子和装饰不能改变经济结果。各章和规划关的参考解法保留在代码测试中，验证目标可达，额外星级确实要求更好的布局。
