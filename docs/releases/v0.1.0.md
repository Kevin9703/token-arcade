# Token Arcade v0.1.0

Turn Claude Code and Codex token history into a playable pixel arcade.

## Play It

- [Try the fictional hosted demo](https://kevin9703.github.io/token-arcade/?demo=1)
- Run the local scanner in one command:

  ```bash
  npx --yes github:Kevin9703/token-arcade
  ```

The hosted demo uses an isolated fictional save. The local version reads
Claude Code and Codex history on your machine, aggregates token totals by
project, and never uploads conversation history or telemetry.

## First Release

- Turn newly discovered tokens into arcade coins.
- Grow every project through 50 cabinet levels and five visual stages.
- Pull capsules and collect 50 pixel-art prizes.
- Display prizes in the room automatically or arrange them in Decorate Mode.
- Unlock permanent collection upgrades, room themes, profile frames, and
  achievements.
- Switch between English and Simplified Chinese.
- Keep live and demo progress in separate local save slots.

## Requirements

- Node.js 22 or newer for the local scanner.
- Local Claude Code or Codex history is optional; the demo remains fully
  playable without it.
