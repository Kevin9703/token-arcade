# Token Arcade v0.1.1

## Startup polish

- Added a dedicated pixel-arcade boot screen for cold starts.
- Preloads the largest Home scene assets before the canvas reveal.
- Waits for every visible Home sprite to decode, so procedural fallback art no
  longer flashes before the finished arcade appears.
- Defers secondary rooms until after Home is interactive.

The hosted demo remains fictional and isolated from local Claude Code or Codex
history.
