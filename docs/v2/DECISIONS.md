## 3. 已否决与未验收实验

**被用户否决：** 本轮深蓝平面标题栏、横向网页按钮、大卡片式底部操作、纸色 DOM 纵向手册，以及未经统一的角色/机器画风。不能只换字体和边框继续当正式方案。

**可研究，但不可当作已完成：** 本轮章节领取、心爱机台和简单移动代码。尚缺跨标签事务、严格存档迁移、完整输入屏蔽、实际伙伴动作、资源与多语言验证。

**概念候选：** `assets/concepts/v2/room-study.png`、`cabinet-study.png`、`character-study.png`。生成发生于用户要求先策划之前，随后暂停 UI 工作完成策划。用户说“嗯你推进”后，继续 P1-A：新增 `ui-study.png`，四张候选图裁切到 `public/assets/cozy-preview/`，用于独立 `/cozy.html`。这次继续制作的授权不等于用户已经认可样板外观，也不等于完整 V2 已实现。

## 6. 决策变更方式

2026-09-06 用户明确反馈：参照对象为重做前的原版街机房间；保留能走的人物、宠物；房间氛围和机器造型可以，但布局、操作与乐趣弱于原版。由此把优先级改为恢复可持续奖励流程、明确空间落点和真实走近互动，不继续整套换美术。实现与核对见 [INTERACTION_REVISION.md](INTERACTION_REVISION.md)。这是修订方向的依据，不意味着用户已认可修订后的结果。

后续用户改变方向时更新本文件，列出影响的章节、数值、UI 和程序模块；不要只改一个页面让其余文档继续讲旧规则。已发布 ID 与存档迁移规则有兼容义务，即使叙事和美术改变也不能默默复用 ID。
